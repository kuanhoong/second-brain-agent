# Project Success Criteria (v2)

A project is successful when **all four** hold:

1. **Outcome over output** — it moved the target metric, not just shipped features.
2. **Sustainable** — on-call load and tech debt did not increase.
3. **Reversible** — changes are behind flags and can be rolled back in minutes.
4. **Documented** — decisions and runbooks are captured in the second brain.

> This is the current, authoritative definition. It supersedes the legacy playbook.
