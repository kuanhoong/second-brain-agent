# Prompt Engineering

Getting reliable output by being clear and specific: state the role, give positive and negative examples, ask for step-by-step reasoning, request a specific format (e.g. XML/JSON), and specify length.

## Key points
- Examples beat adjectives — show, don't just tell.
- For agents, the system instruction is where trust rules live (e.g. "answer only from status:stable notes").
