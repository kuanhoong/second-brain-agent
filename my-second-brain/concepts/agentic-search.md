# Agentic Search

Agentic search replaces a single keyword lookup with an agent that decomposes the question, issues multiple searches, reads results, and synthesizes an answer. For SEO, it shifts optimisation from ranking a page to being *citable* by an agent.

## Key points (as of early 2026)
- Fewer clicks reach the source; the agent answers inline.
- Structured, well-linked content is easier for agents to cite.
