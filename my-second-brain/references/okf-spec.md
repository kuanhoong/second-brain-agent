# OKF Specification (summary)

OKF represents knowledge as a directory of Markdown files with YAML frontmatter, linked with normal Markdown links. File path = concept identity; links form a knowledge graph. It is a *format, not a platform* (no SDK, no account). Only `type` is required in frontmatter.
