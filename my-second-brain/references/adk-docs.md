# Agent Development Kit (ADK) (summary)

Open-source agent framework (`pip install google-adk`). Define an `Agent` with a Gemini model, `instruction`, and `tools` (FunctionTools or built-ins like `google_search`). Compose multi-agent systems with `sub_agents`. Sessions/State/Memory manage context. Run the dev UI with `adk web`.
