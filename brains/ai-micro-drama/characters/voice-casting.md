# Summary

A character's voice is part of their identity, the same as their face. Pick one voice per character and hold it across every episode and every dubbed language, so the lead sounds like the lead everywhere.[^morphic-dubbing]

# Key points

- Native-audio models such as Veo 3.1 generate dialogue in the clip, so describe the voice in the prompt (age, tone, pace) and keep that description identical across shots.[^google-veo31]
- If you generate voices separately, use a cloned or designed voice and only clone voices you have the rights to ([likeness and consent](/distribution/likeness-and-consent.md)).
- Record the voice description in the [character bible](/characters/character-bible.md).
