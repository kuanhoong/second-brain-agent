# Summary

When a character's look changes (a wedding dress, a bruise, the makeover after the revenge plot turns), make a separate sheet for that beat and attach the active beat's sheet to every prompt in it.[^invideo-costume]

# Key points

- Keep the face reference constant across beats and change only the wardrobe reference.
- In micro drama the costume change is often the story: the humiliated heroine's transformation is a reveal shot. Plan it in the [episode grid](/writing/episode-grid.md).
- Record which sheet each episode uses in the shot list so continuity checks are possible ([shot list](/templates/shot-list-template.md)).
