# Summary

Most video models learned on horizontal footage, so setting a 9:16 canvas is not enough. Name the orientation in every prompt and describe what fills the top, middle and bottom of the frame.[^invideo-vertical]

> Vertical 9:16 frame, close-up, her face in the top third, rain-streaked window filling the lower two thirds.

# Key points

- Set 9:16 at project level so every shot inherits it.[^invideo-vertical] Veo 3.1 outputs 9:16 natively.[^google-veo31]
- For shot types that keep coming back horizontal, storyboard a vertical still and animate from it.[^invideo-vertical]
- Never crop a wide shot to vertical: the result is a frame with nothing composed in it.[^pexo-make]
