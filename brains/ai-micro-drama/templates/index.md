# Templates

* [Character Bible Template](character-bible-template.md) - Fill-in template for who a character is: want, wound, secret, power arc and voice. (draft)
* [Character Sheet Template](character-sheet-template.md) - Fill-in template for one character's visual reference: the images to generate and the identity block to paste into prompts. (draft)
* [Episode Grid Template](episode-grid-template.md) - Fill-in season planner, ten episodes per block, with the paywall row marked. (draft)
* [Episode Script Template](episode-script-template.md) - Fill-in template for one 60 to 120 second vertical episode, built on the four-beat structure. (draft)
* [Shot List Template](shot-list-template.md) - Fill-in template that turns a script into generatable shots, with the references and continuity each one needs. (draft)
* [Video Prompt Template](video-prompt-template.md) - Fill-in prompt for one vertical micro-drama shot, combining the five-part formula, 9:16 layout, audio and a style block. (draft)
