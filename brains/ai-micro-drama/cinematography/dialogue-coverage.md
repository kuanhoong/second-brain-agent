# Summary

A 9:16 frame has no width for a conventional side-by-side two-shot, so stage most exchanges as alternating singles and let the cut carry the conversation.[^invideo-vertical]

# Options

- **Alternating singles:** one face per shot, cut on each line. The safest choice for AI, since each shot needs one character reference.[^invideo-vertical]
- **Over-the-shoulder:** look past one character's soft shoulder to the other's sharp face. Anchors the viewer in the conversation.[^morphic-ots]
- **Vertical two-shot:** both faces close in one frame, for confrontation or romance; describe how close they stand, because the gap between them is the story.[^morphic-two-shot]

# Key points

- Generate three or four options per shot so the edit has coverage.[^invideo-vertical]
- Keep both characters on the same side of the line in every shot ([continuity](/cinematography/continuity-and-the-180-rule.md)).
