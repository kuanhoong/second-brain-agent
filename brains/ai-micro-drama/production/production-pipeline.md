# Summary

A practical pipeline has eight stages. Each stage produces an artefact the next one consumes, and the expensive step (video generation) comes late, after everything is approved as text or stills.

1. **Premise and trope** ([genres](/industry/genres-and-tropes.md)).
2. **Series bible and episode grid** ([bible](/characters/series-bible.md), [grid](/writing/episode-grid.md)).
3. **Scripts**, one per episode ([template](/templates/episode-script-template.md)).
4. **Character sheets and location references**, locked ([character sheet](/characters/character-sheet.md)).
5. **Shot list and storyboard stills** ([storyboard first](/production/storyboard-first.md)).
6. **Video generation**, shot by shot, routed to the right model ([shot routing](/production/shot-routing.md)).
7. **Edit, sound, captions** ([editing](/production/editing-and-pacing.md)).
8. **Label and publish** ([AI labels](/distribution/ai-disclosure-labels.md)).

# Key points

- Stage the pipeline for vertical from the start: premise, episode structure, vertical staging, a consistent cast, cliffhangers, 9:16 export.[^pexo-make]
- Agent-based tools now run much of this chain, with AI agents handling the direction layer.[^invideo-definition] Keep the approval points human.
