# Summary

Dubbing a micro drama means transcribing, translating, re-voicing timed to the original and lip-syncing each mouth to the new track.[^morphic-dubbing] Audio-first tools such as ElevenLabs Dubbing Studio translate and re-voice, but the mouth still moves to the original language, so on-screen speakers need a separate lip-sync pass.[^perso-dubbing]

# Key points

- Keep one voice per character across every language.[^morphic-dubbing]
- Plan it as a repeatable per-episode sequence; a season into several markets becomes throughput.[^morphic-dubbing]
- Translation is not localisation: a trope may need a new setting for a new market.[^conversation-tropes]
