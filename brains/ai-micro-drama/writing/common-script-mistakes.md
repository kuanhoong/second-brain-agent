# Summary

Most vertical scripts fail because the writer treated the format as shortened television.[^filmustage-script]

# Key points

- Adapting a horizontal script instead of writing vertical from the start.[^filmustage-script]
- Ensembles larger than two or three central characters.[^filmustage-script]
- Long setups that delay the conflict.[^filmustage-script]
- Action sequences that depend on wide spatial storytelling.[^filmustage-script]
- Endings that resolve instead of pulling forward.[^filmustage-script]
- Too much plot for one episode. Split it into two.
