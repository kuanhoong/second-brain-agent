# Summary

Plan the season as a grid: one table per block of ten episodes, one row per episode, with the hook, the beat, the cliffhanger, the location and the cast.[^storyflow-script]

# Key points

- Label the paywall row so the whole team knows which cliffhanger has to sell the season.[^storyflow-script]
- Check every row ends on a question rather than an answer.[^storyflow-script]
- The location and cast columns double as a production plan: they tell you which character sheets and location references each block needs.
