# Concepts

* [Agent Development Kit](agent-development-kit.md) - Google's open-source framework for building, debugging and deploying AI agents in code.
* [Gemini Models](gemini-models.md) - Which Gemini model IDs to use for agents and note-taking work. (stale)
* [Knowledge Graph](knowledge-graph.md) - A network of concepts as nodes and the relationships between them as edges. (draft)
* [LLM Wiki Pattern](llm-wiki-pattern.md) - A personal knowledge base of interlinked markdown files that an LLM agent writes and maintains over time.
* [OKF Change Tracking (v0.1)](okf-change-tracking-v0-1.md) - How OKF v0.1 recorded a concept's last change and its sources. Superseded by v0.2. (deprecated)
* [OKF Trust Signals](okf-trust-signals.md) - The optional OKF v0.2 frontmatter families that record provenance, trust and lifecycle for each concept.
* [Open Knowledge Format](open-knowledge-format.md) - Google Cloud's open, vendor-neutral spec for knowledge as a directory of markdown files with YAML frontmatter.
* [Retrieval-Augmented Generation](retrieval-augmented-generation.md) - Grounding a model's answer in passages retrieved from an external store at query time.
* [Second Brain](second-brain.md) - An external, trusted system that stores, organises and connects what you learn so your head is free to think.
