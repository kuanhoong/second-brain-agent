# Summary

In OKF v0.1 a concept's last change is recorded in a single `timestamp` frontmatter field, and its sources are listed in a `# Citations` section at the end of the body.

# Key points

- Use `timestamp` to record when a concept last changed.
- List sources as bullets under a `# Citations` heading.
