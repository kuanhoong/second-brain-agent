# Summary

A knowledge graph stores what you know as nodes and the links between them. In a markdown knowledge base the graph is implicit: every file is a node and every link between files is an edge, so the graph grows as a side effect of writing.

# Key points

- Links surface connections that folders hide.
- Shared tags give a second, looser kind of edge.
- A link to a page that does not exist yet is a visible to-do.
